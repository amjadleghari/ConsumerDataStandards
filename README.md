# Coralbay Open Data Standard - documentation (fictitious)

This repository holds the documentation site for the Coralbay Open Data
Standard, a fictitious API standard for consumer data sharing. The site is a
worked example that uses OpenAPI, OpenAPI Overlays, Arazzo workflows, contract
documentation and Mermaid diagrams, built with Docusaurus.

> **Fictitious example.** Every organisation, person, product and value on
> this site is invented. The site is not an official publication of the Data
> Standards Body, the Treasury, or any other body.

Build and contribute: see CONTRIBUTING.md.
